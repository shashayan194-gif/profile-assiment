- style.css: design, colors, layout, responsive styles
- script.js: mobile menu and contact button behavior

HOW TO RUN
1. Extract this folder if it is zipped.
2. Open Visual Studio Code.
3. Click File > Open Folder and choose my-portfolio.
4. Open index.html.
5. If you have the Live Server extension, right-click index.html and choose Open with Live Server.
   Otherwise, double-click index.html in File Explorer to open it in your browser.
